## Part 2

The website was enhanced for WED5020 Part 2 with CSS styling and responsive design.

### CSS Improvements
- Added external CSS using styles/common.css.
- Added typography, colours, backgrounds and spacing.
- Added Flexbox for the header and navigation.
- Added CSS Grid for product and content cards.
- Added borders, rounded corners and box shadows.
- Added hover, focus and active states for interactive elements.

### Responsive Design
- Added tablet layout using media queries.
- Added mobile layout using media queries.
- Used relative units such as %, rem and vw.
- Added responsive images using max-width: 100% and srcset.

### Testing
The website was tested at desktop and mobile screen sizes using browser developer tools.
The mobile layout was checked to confirm that the navigation, headings and content adjust to a smaller screen.

### JavaScript
The enquiry form was tested using JavaScript validation and displays a confirmation message after a successful submission.
